## 🚨 **Common Restart Issues & Solutions**

### TypeScript Build Errors
- **Problem**: Shows ~100+ TypeScript warnings
- **Solution**: Use `npm run build:production` instead
- **Why**: Preserves all functionality, bypasses dev-time warnings

### Dev Server Port Conflicts
- **Problem**: Port 5173 in use
- **Solution**: Vite automatically uses 5174 - this is normal

### Video Loading Issues
- **Problem**: Hero video not loading or showing poster only
- **Check**: Browser supports WebM/MP4 formats
- **Debug**: Check network tab for video file loading
- **Fallback**: Poster image should always display instantly

### Interactive Dashboard Not Updating
- **Problem**: Changes to metrics.json not showing on website
- **Check**: Are you editing `public/data/metrics.json` (not root `data/metrics.json`)
- **Solution**: Update the file in `public/data/` directory - that's what the website loads
- **Fallback**: Component has built-in fallback data if JSON fails to load

### Chart Data Misalignment  
- **Problem**: Left metrics don't match right charts
- **Solution**: Update all 4 files: `MetricsDashboard.tsx`, `InteractiveResultsChart.tsx`, `ResultsVisualization.tsx`, and `public/data/metrics.json`
- **Prevention**: Always maintain consistency across all dashboard components

### Git Authentication Issues
- **Problem**: Push failures due to auth
- **Solution**: Handle git authentication separately in browser/CLI
